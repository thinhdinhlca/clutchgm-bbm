# clutchgm-bbm

The Basketball Monster redesign from ClutchGM, packaged as static files for a
userscript on iOS, where Chrome extensions cannot run.

Install: open https://thinhdinhlca.github.io/clutchgm-bbm/bbm-ios.user.js in Safari with a userscript manager
(Userscripts, Stay, or similar) and accept the install.

The files are generated by `npm run build:ios` in the ClutchGM project and
published by `npm run publish:ios`. They are a copy of that project's
`src/bbm-*.js`, `src/scoring.js`, `src/bbm.css` and `src/assets/nba/*.png`,
with the JavaScript concatenated into one bundle. `build.json` records the
sha256 of every source file each hosted file was built from.
